# بيّنة - قضيتي

تطبيق عربي لإدارة القضايا والجلسات والوكالات والمهام والاستحقاقات، مع أداة لحساب ضريبة القيمة المضافة وأرشفة إقراراتها وتصدير تقارير Excel.

الإصدار في `package.json`: **1.0.12**. الواجهة React وTypeScript وVite، وتطبيق سطح المكتب Electron مع تخزين محلي عبر `sql.js`.

## التشغيل

يتطلب Node.js وpnpm. نفّذ الأوامر من جذر نسخة المشروع:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

للبناء أو تشغيل تطبيق سطح المكتب:

```sh
pnpm build
pnpm desktop
```

لإنشاء مثبّت Windows:

```sh
pnpm desktop:dist
```

## منطق المهام والقيمة المضافة

يوجد الشرح العربي والمقتطفات الأصلية ومراجع الأسطر في [docs/logic-extraction](docs/logic-extraction/). المقتطفات ملفات مرجعية؛ تعتمد على سياق التطبيق وليست مكتبة مستقلة.

معظم منطق الواجهة في `src/App.tsx`. التخزين المكتبي في `electron/main.cjs` وجسر الاتصال في `electron/preload.cjs`.

## محتويات النسخة العامة

أُفرغت قوائم القضايا والوكالات والتفويضات الأولية، واستُبدل اسم المستخدم والمؤسسة الافتراضيان بقيم عامة. لم تُضمّن قواعد بيانات المستخدم أو المرفقات أو النسخ الاحتياطية أو الإصدارات التنفيذية أو مفتاح الترخيص الخاص أو ملفات التفعيل. `electron/license-public.pem` مفتاح تحقق عام.

بعض وثائق الإصدار القديمة تتناول آلية الترخيص السابقة؛ الاختبار الحالي يثبت سياسة الوصول المفتوح. كما يرقّي التطبيق الحالي الحسابات تلقائيًا إلى مسؤول، ولذلك يحتاج فصل صلاحيات الموظفين إلى مراجعة قبل الاعتماد عليه.

حسابات VAT تعكس التنفيذ البرمجي الحالي. الشرح يحدد المعدلات والقيود الموجودة في الكود، ومنها معدل صفر لبند الاحتساب العكسي. لم تُجر مراجعة امتثال ضريبي.

## التحقق

```sh
node --test tests/open-access-policy.test.cjs
pnpm exec tsc --noEmit -p tsconfig.app.json
```

ملفات التثبيت والتبعيات ومخرجات البناء تُنتج محليًا، ولا تُحفظ في المستودع.
